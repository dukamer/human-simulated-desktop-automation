# 📂 Sample Automation Templates

Ready-to-use JSON templates designed for **Multi-Task AutoClick Studio**. Each script can be directly imported into the application.

## 📦 Included Templates

| Template File | Workflow Name | Target Use-Case |
|---|---|---|
| `template_1_daily_testnet_checkin.json` | **Daily Testnet Check-in** | Automated login and web3 transaction signing with sub-pixel jitter. |
| `template_2_faucet_auto_claim_jitter.json` | **Periodic Faucet Claimer** | Periodic faucet claim routine with randomized Gaussian delays. |
| `template_3_multi_tab_adspower_sync.json` | **Multi-Window Browser Sync** | Parallel execution across multiple AdsPower/GoLogin windows. |
| `template_4_mmo_afk_anti_ban.json` | **MMO Anti-AFK Routine** | Simulates natural human presence with randomized gestures. |
| `template_5_office_form_repeater.json` | **Office Batch Form Repeater** | Fast keyboard navigation and data entry with 50ms killswitch. |

## 🚀 How to Import

1. Download or clone this repository.
2. Launch **Multi-Task AutoClick Studio** on Windows 10/11.
3. In the application menu, select **Import Script (JSON)**.
4. Select any `.json` file from this directory.
5. Hit **`Space`** to adjust coordinates to your personal screen resolution if necessary.
6. Press **`F5`** (or the tab's dedicated hotkey) to start!
